# Odontix — Dental Clinic Simulator

Dental Clinic Simulator is an Android game created under the Odontix name by Dr. Taniya Gandhi, BDS. It gives players a virtual dental-clinic setting in which to explore selected preclinical activities and dentistry-themed case scenarios.

The project has two parts:

- **The Android game:** interactive activities involving a mouth mirror, bur categories and selected virtual clinical scenarios.
- **The website:** an overview of the game, a player guide, an educational dental learning resource and project information.

## Educational scope

The game is intended for education and entertainment. Its activities are simplified simulations; they are not clinical protocols, patient-specific advice or a substitute for recognised dental education and supervised practical training.

The website's learning guide is an introductory resource. For academic or clinical decisions, consult current textbooks, professional guidance and qualified dental educators.
